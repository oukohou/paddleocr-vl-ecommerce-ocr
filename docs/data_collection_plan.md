# 数据采集方案与版权风险提示

## ⚠️ 关于爬取淘宝/京东的版权风险（必须阅读）

### 法律风险

| 风险类别 | 具体说明 | 严重程度 |
|:---|:---|:---|
| **著作权侵权** | 商品详情页图片（商品图、模特图、设计素材）的版权归商家/品牌方所有，未经授权爬取和使用可能构成侵权 | **高** |
| **平台服务条款** | 淘宝/京东用户协议明确禁止自动化爬取、数据抓取等行为，违反可能导致账号封禁甚至法律追责 | **高** |
| **反爬对抗** | 淘宝/京东具备业界顶级的反爬机制（滑块验证、行为检测、IP封禁、动态渲染等），大规模爬取技术难度极高 | **中** |
| **比赛合规** | 比赛要求数据集"开源"，若数据集涉及第三方版权图片，开源后可能引发版权纠纷 | **高** |

### 结论

**不建议直接爬取淘宝/京东商品详情页图片。** 版权风险明确，且平台反爬机制强，4天时间内投入产出比极低。

## ✅ 推荐替代数据采集方案

### 方案一：公开OCR数据集 + 领域适配（推荐）

| 数据集 | 来源 | 特点 | 适用性 |
|:---|:---|:---|:---|
| **CTW1500** |  curved text in the wild | 包含弯曲文本、自然场景 | 艺术字体可参考 |
| **Total-Text** |  弯曲/多方向文本 | 多样化文本形状 | 版式复杂场景 |
| **ICDAR 2019-LSVT** |  大规模场景文本 | 含部分商品图片 | 最接近电商场景 |
| **SynthText** |  合成数据 | 海量、无版权风险 | 快速扩充训练集 |
| **百度开源数据集** |  PaddleOCR官方 | 与比赛基座模型同源 | 兼容性好 |

**执行建议**：
1. 从 ICDAR-LSVT 等公开数据集中筛选与"图文混排"相关的子集
2. 使用 SynthText 生成带复杂背景的合成文本图片补充训练集
3. 自己手动截图少量公开页面（10-20张）作为测试集，属于合理使用

### 方案二：合成数据生成（最快、最安全）

使用代码自动生成带复杂背景的文本图片：

```python
# 核心思路：将文本渲染到各种背景图上
# 1. 收集无版权背景图（unsplash API、纯色背景、纹理背景）
# 2. 使用 PIL/cv2 将文本以不同字体、颜色、大小渲染到背景上
# 3. 模拟电商详情页特征：多列布局、图文穿插、艺术字体
```

**优势**：零版权风险、可控制数据分布、可批量生成、标注自动完成

### 方案三：手动截图 + 快速标注（评估集推荐）

对于评估集（比赛要求开源），建议：
1. 手动打开少量公开电商页面，截图保存（10-30张）
2. 使用 PPOCRLabel 或自建脚本进行标注
3. 评估集规模小但质量高，符合"高质量评估集贡献奖"评选标准

## 📊 数据规模建议

| 数据类型 | 数量 | 来源 | 用途 |
|:---|:---|:---|:---|
| 训练集 | 500-1000张 | 公开数据集 + 合成数据 | 模型微调 |
| 验证集 | 100张 | 公开数据集子集 | 训练过程评估 |
| 测试集 | 100张 | 手动截图/合成 | 最终评估（需开源） |

## 🔧 自动化标注脚本设计

详见 `scripts/annotate_data.py`，支持以下标注模式：

1. **全图OCR模式**：输入图片，输出图片中全部文本内容
2. **区域OCR模式**：输入图片+区域坐标，输出指定区域文本
3. **表格识别模式**：输入表格图片，输出OTSL格式结构化表格

## 最终建议

考虑到 **4天Deadline** 和 **版权风险**，建议采用：

> **训练集**：公开数据集（ICDAR-LSVT子集 300张）+ 合成数据（500张）
> **评估集**：手动截图/合成数据（100张），确保开源无风险
> **标注方式**：合成数据自动生成标注 + 人工复核

这样可以在 **1天内完成数据准备**，剩余3天全部用于模型微调和文档撰写。
